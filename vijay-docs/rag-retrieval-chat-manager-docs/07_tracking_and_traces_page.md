# 07 — Tracking & End-to-End Traces Page

## 1. Executive Summary & Page Purpose
The **Tracking & End-to-End Traces Page** (`TrackingPage.tsx`, route: `/tracking`) delivers granular OpenTelemetry-style distributed tracing for every RAG message generated by the system. It visualizes the execution timeline across retrieval, reranking, prompt building, LLM streaming, and guardrail validation spans.

## 4. Backend APIs & Contracts

| Method | Endpoint | Description | Request / Response |
|---|---|---|---|
| `GET` | `/tracking/traces` | Lists recent execution traces with filters | `list[TraceSummary]` |
| `GET` | `/tracking/traces/{trace_id}` | Retrieves full span hierarchy and payloads | `TraceDetailRecord` |
| `GET` | `/tracking/traces/{trace_id}/spans` | Retrieves OpenTelemetry-compliant JSON span tree | `list[SpanRecord]` |
